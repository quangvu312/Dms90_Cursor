# Skill: Brainstorm Solution

## Mục tiêu

Sau khi đã hoàn thành:

- Discovery

- Scope Analysis

Hãy đề xuất các hướng giải quyết phù hợp.

Không viết Specification.

Không viết User Story.

Không sinh code.

---

## Cách thực hiện

Luôn bắt đầu bằng việc tóm tắt yêu cầu.

Sau đó đề xuất từ 2 đến 4 phương án.

Ví dụ:

Phương án A

...

Ưu điểm

...

Nhược điểm

...

------------------------

Phương án B

...

Ưu điểm

...

Nhược điểm

...

---

## Cần phân tích

Đối với mỗi phương án cần đánh giá:

- Có đơn giản không?

- Có ảnh hưởng dữ liệu cũ không?

- Có ảnh hưởng Mobile không?

- Có ảnh hưởng API không?

- Có cần migrate dữ liệu không?

- Có cần Config mới không?

---

## Nếu có nhiều phương án

Hãy so sánh.

Ví dụ

| Tiêu chí | PA A | PA B |

|----------|------|------|

| Độ đơn giản | ✓ | |

| Ít ảnh hưởng | ✓ | |

| Dễ bảo trì | | ✓ |

| Khả năng mở rộng | | ✓ |

Sau đó đề xuất phương án phù hợp nhất.

---

## Luôn ưu tiên

- Đơn giản

- Ít ảnh hưởng hệ thống

- Dễ bảo trì

- Dễ mở rộng
