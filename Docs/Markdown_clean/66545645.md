### Import kiểm kho

| # | Title | User interaction and wireframe | Description |

| 1 | Popup Import |  | **1. Đường dẫn:** Danh sách phiếu kiểm kho → Import kiểm kho  **2. Mô tả:** Khi click vào import kiểm kho, hệ thống hiển thị Popup Import kiểm kho bao gồm:   * Nút **Lấy file mẫu**: Click vào nút → hệ thống thực hiện hiển thị popup Lấy file mẫu đươc mô tả bên dưới: * Nút **Tải lên**: Người dùng chọn vào kéo thả file import vào ô "Chọn hoặc kéo file đến vị trí này" * Nút **Tiến hành xử lý**:   + Mặc định disable, enable khi có file được import.   + Click vào nút -> nhấn nút "Tiến hành xử lý" để import file dữ liệu vào hệ thống. Chỉ cho phép import file excel, tối đa 10000 dòng.     - Nếu file không đúng định dạng của template (thiếu column, sai column name), báo lỗi *"<column Name 1>, <column name 2>, ..., <column name n> là bắt buộc.*     - Nếu file không có dữ liệu, báo lỗi: *"File import không đúng định dạng. Vui lòng kiểm tra lại" (theo báo lỗi của team 2).*     - Nếu file vượt quá số dòng cho phép, báo lỗi: *"File import vượt quá số dòng cho phép (tối đa 10000 dòng)!"*     - Nếu dữ liệu *Ngày kiểm kho, Kênh bán hàng, Kho* (Ngày kiểm kho, Tên kênh bán hàng, Mã kênh bán hàng, Tên kho, Mã kho) khác nhau trên từng dòng sản phẩm, báo lỗi chung: "<Tên trường 1>, <Tên trường 2> không đồng nhất."     - Trường hợp không đồng nhất Mã kênh bán hàng/Tên kênh bán hàng hoặc Mã kho/Tên kho, <Tên trường> chỉ show *Kênh bán hàng* hoặc *Kho*. Ví dụ: Mã kênh bán hàng, Tên kênh bán hàng, Ngày kiểm kho ko đồng nhất thì báo lỗi *"Kênh bán hàng, Ngày kiểm kho không đồng nhất."*  Nếu có ít nhất 1 dữ liệu lỗi, hệ thống thực hiện show popup Chi tiết Import phiếu kiểm kho - Trạng thái "Thất bại" được mô tả bên dưới.  Nếu toàn bộ dữ liệu trong file đều hợp lệ, hệ thống thực hiện:   * Tạo mới phiếu kiểm kho với dữ liệu trong file với trạng thái "Khởi tạo".   + Ngày tạo: = Thời điểm import thành công.   + Người tạo: = username của tài khoản thực hiện import.   + Tự động gen mã phiếu kiểm kho theo quy tắc của hệ thống.   + Trường Tồn kho hệ thống trên phiếu cập nhật lại theo tồn kho tại thời điểm tạo thành công. * Nếu trường Tồn kho thực tế của sản phẩm/lô bị bỏ trống, mặc định = Tồn kho hệ thống của sản phẩm/lô tương ứng. * Đối với hệ thống có config sử dụng lô, hệ thống thực hiện sum tất cả tồn kho theo lô của sản phẩm thành tồn kho của sản phẩm đó. |
