# Danh sách các màn hình chặn vuốt ngang 2 bên thành thiết bị

* Các màn hình nằm trong danh sách này sẽ chặn vuốt ngang 2 bên thành thiết bị để tránh sai sót trong quá trình kiểm tra dữ liệu
* Các màn hìnhkhông được liệt kê sẽ có thể vuốt ngang 2 bên thành thiết bị

|  | Module | Màn hình chặn |
| --- | --- | --- |
| 1 | Bày hàng | Chụp hình bày hàng |
| 2 | Chấm công | * Chấm công đầu ngày * Chấm công cuối ngày |
| 3 | Khảo sát | * Checkin khảo sát * Thực hiện khảo sát |
| 4 | Viếng thăm | * Checkin * Checkout * Tạo ghi chú cửa hàng |
| 5 | Điểm bán | Tạo mới điểm bán |
| 6 | Điểm bán | Chỉnh sửa điểm bán (Tất cả các UI chỉnh sửa) |
| 7 | Yêu cầu hỗ trợ | Tạo yêu cầu hỗ trợ |
| 8 | Kiểm tra tồn kho | * Tạo mới kiểm tra tồn kho * Thêm sản phẩm * Bộ lọc tìm kiếm  * Tạo ghi chú tồn kho |
| 9 | Đặt hàng | * Tạo đơn hàng   + Chọn sản phẩm   + Bộ lọc tìm kiếm   + Xác nhận đơn hàng |
