1. URI: /v1/integrations:filter-promotions
  2. Method: GET

  3. Query Parameters:

    1. distributor_id (optional):
      1. Mô tả: Id của nhà phân phối. Nếu không có tuyến → không truyền distributor_id, ngược lại có tuyến sẽ truyền distributor_id
      2. Kiểu dữ liệu: string
  4. Response: Gồm danh sách CTKM gồm các thuộc tính theo yêu cầu và tổng số lượng CTKM
