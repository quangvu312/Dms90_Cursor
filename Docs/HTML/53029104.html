1Vùng buttonĐầy đủ các button chức năng (Tạo mới, nhập dữ liệu, xuất dữ liệu)
2Bộ lọc

UI + mô tả bộ lọc

Ít nhất phải có lọc theo:

  • Phân cấp Vùng
  • NPP
  • Trạng thái
3Tìm kiếmTìm kiếm theo field nào trên lưới danh sách
4Lưới danh sáchSắp xếp các cột trên lưới danh sách hợp lý
5Lưới danh sáchCác trường thông tin lấy từ màn hình khác phải có Mã + Tên
6Lưới danh sáchCác cột chỉ có Mã, phải có chức năng copy
7Lưới danh sáchCó đầy đủ 4 cột thông tin: Ngày tạo, Người tạo, Ngày cập nhật, Người cập nhật
8Chức năng Tùy chỉnhCác thao tác có thể thực hiện trong chức năng tùy chỉnh

Màn hình thêm mới
9Tất cả các field

Mô tả bắt buộc/Không bắt buộc

Có thể nhập liệu/không nhập liệu (disable/enable)

10Field dạng text

Hệ thống tự sinh hay User tự nhập

  • Hệ thống tự sinh: Sinh ra theo quy tắc nào
  • User tự nhập: Nhập được bao nhiêu ký tự
11Field dạng dateFormat date hay date time, chỉ lưu ngày hay cần cả ngày và giờ, phút, giây
12Field dạng select

Chọn 1 hay chọn nhiều

Dữ liệu lấy từ đâu hay load cứng các giá trị nào

Mô tả popup hiển thị gồm các trường nào (doc + UI)

Nếu chỉ cần show dropdown, thì dropdown hiển thị các cột nào

13Field dạng số

Format hàng nghìn hay Format tiền tệ

Phải format khi user đang nhập liệu

14Field dạng checkbox

Mặc định check hay uncheck

Mô tả rõ: Check vào thì thế nào/Uncheck thì thế nào

15Field dạng toggle

Mặc định gạt sang trái hay sang phải

Mô tả rõ: gạt sang trái thì thế nào/gạt sang phải thì thế nào

16Field chọn trạng thái

Mô tả flow trạng thái nếu trạng thái phức tạp


Trường hợp Hoạt động/ngưng hoạt động thì mô tả:

Hoạt động → Ngưng hoạt động phải check điều kiện gì, dữ liệu thay đổi thế nào

Ngưng hoạt động → Hoạt động phải check điều kiện gì, dữ liệu thay đổi thế nào

17Field Ghi chú

Các màn hình luôn xem xét có cần field Ghi chú hay không.

Mặc định sẽ có ghi chú, các màn hình ko cần có thể xem xét bỏ ra.

18Button LưuCheck các điều kiện khi lưu dữ liệu
19Button HủyCheck các warning khi Đóng màn hình hoặc hủy thao tác
20Template Import

Phải có template import

Template mô tả trường nào bắt buộc nhập

Nhập mã hay nhập tên, nếu nhập mã thì user tự input hay nhập mã theo quy tắc nào

21Template Export

Phải có điều kiện xuất dữ liệu, ko cho xuất tất cả

Phải có template export, template export phải có đủ các trường "Tên..."
