# Icons

> Ghi nhận từ website ht-portal-uat.finviet.com.vn

## Framework

- Sử dụng **Ant Design Icons** (inline SVG)
- Menu sidebar: icon 16×16px, opacity ~0.65

## Icons quan sát

| Vị trí | Icon |
|--------|------|
| Sidebar menu items | Line icons (folder, cart, warehouse, etc.) |
| Header - Upload | Arrow up tray |
| Header - Download | Arrow down tray |
| Header - Notification | Bell |
| Header - Language | Globe |
| Filter button | Funnel |
| Date picker | Calendar |
| Table action | Printer |
| Search | Magnifying glass |
| Menu expand | Chevron right (›) |
| Modal close | × |
| Pagination | ‹ › arrows |
| FAB (bottom right) | Chat bubble (yellow circle) |

## Kích thước

| Context | Size |
|---------|------|
| Menu icon | 16×16px |
| Header icon button | 32×32px container |
| Button icon | 14px |
| Stat card icon | 48×48px container |

## Prototype note

Prototype sử dụng emoji/unicode placeholder cho icons. Khi tích hợp production nên thay bằng Ant Design Icons hoặc SVG sprite.
