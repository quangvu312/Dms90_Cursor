# Colors

> Ghi nhận từ website ht-portal-uat.finviet.com.vn (Ant Design customized)

## Primary

| Token | Giá trị quan sát | Sử dụng |
|-------|------------------|---------|
| Primary | `#2B579A` / `rgb(43, 87, 154)` | Button primary, link, stat value |
| Primary shadow | `rgba(0, 35, 65, 0.2) 0px 2px 0px` | Button primary box-shadow |

## Background

| Token | Giá trị quan sát | Sử dụng |
|-------|------------------|---------|
| Layout | `#F5F5F5` / `rgb(245, 245, 245)` | Main content area (`.ant-layout-content`) |
| Container | `#FFFFFF` | Sidebar, Card, Modal, Input |
| Table header | `#FAFAFA` | Table thead background |

## Text

| Token | Giá trị quan sát | Sử dụng |
|-------|------------------|---------|
| Primary text | `rgba(0, 0, 0, 0.88)` | Body, table cell |
| Secondary text | `rgba(0, 0, 0, 0.45)` | Breadcrumb, placeholder |
| Heading | `rgba(0, 0, 0, 0.79)` | Page title h1 |
| Inverse | `#FFFFFF` | Text trên button primary |

## Border

| Token | Giá trị quan sát |
|-------|------------------|
| Default border | `#D9D9D9` / `0.8px solid` |
| Secondary | `rgba(0, 0, 0, 0.06)` |

## Menu

| Trạng thái | Giá trị quan sát |

## Hover / Active / Disabled

| Component | Hover | Active | Disabled |
|-----------|-------|--------|----------|
| Button primary | Darker blue (observed transition) | Darker blue | Opacity reduced, no pointer |
| Input | Border → primary color | Focus ring | Gray background `#F5F5F5` |
| Table row | `rgba(0,0,0,0.02)` background | — | — |
