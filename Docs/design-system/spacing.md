# Spacing

> Ghi nhận từ website ht-portal-uat.finviet.com.vn

## Scale quan sát

| Token | Giá trị | Vị trí quan sát |
|-------|---------|-----------------|
| xs | 4px | Input internal padding vertical |
| sm | 8px | Table cell padding, menu item margin |
| md | 16px | Card body padding, form gap |
| lg | 24px | Content area horizontal padding |
| xl | 32px | — |

## Padding quan sát

| Element | Padding |
|---------|---------|
| Button primary | `0 15px` |
| Table th/td | `8px` |
| Card body | `16px 24px` (approx) |
| Modal header/body | `16px 24px` |
| Breadcrumb | `18px 0 0` (top) |
| Header | `0 50px` horizontal |
| DatePicker input | `4px 11px` |
| Tag | `0 7px` |

## Margin quan sát

| Element | Margin |
|---------|--------|

| Menu item | `2px 8px` |
| Card | `0 0 16px 0` (bottom gap) |
