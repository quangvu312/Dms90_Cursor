# Typography

> Ghi nhận từ website ht-portal-uat.finviet.com.vn

## Font Family

```css
-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif
```

## Font Sizes

| Element | Size | Weight | Line Height |
|---------|------|--------|-------------|
| Body | 14px | 400 | 22px |
| Body (layout) | 14px | 400 | 16.1px |
| Small / Tag | 12px | 400 | 20px |
| h5 / Card title | 16px | 600 | 24px |
| h1 / Page title | 18px | 600 | 32px |
| Button | 14px | 400 | 22px |
| Breadcrumb | 14px | 400 | 22px |
| Table header | 14px | 600 | 22px |

## Heading hierarchy quan sát

- **Page title**: 18px, semibold, màu `rgba(0,0,0,0.79)`
- **Section title (h5)**: 16px, semibold, màu `rgba(0,0,0,0.88)`
- **Card title**: 14px, semibold
- **Form label**: 14px, regular

## Link

- Màu: primary blue `#2B579A`
- Hover: underline

## Responsive

- Font size không thay đổi rõ rệt trên viewport desktop quan sát (1920px)
- Chưa quan sát breakpoint mobile chi tiết
